### Added

- Initial monorepo scaffold with pnpm workspaces
- Plugin architecture with auto-discovery registry
- Ink-powered interactive discovery TUI
- `dev doctor` — environment diagnostics
- `dev ports` — port listing and process killing
- `dev docker` — containers, images, volumes, networks, disk usage
- `dev git` — branch status, ahead/behind, stash, log
- `dev jwt` — decode, encode, validate JWT tokens
- `dev json` — format, minify, validate, YAML conversion
- `dev uuid` — UUID v4, v7, NanoID, ULID generation
- `dev qr` — QR code generation
- `dev env` — .env / .env.example comparison
- `dev repo` — project analysis (framework, language, architecture)
- `dev ai` — error explanation (local heuristics + AI-powered)
- CI/CD pipeline (lint, typecheck, test, build, release)
- Conventional Commits enforcement via Husky
- 159 unit tests across 13 test files
